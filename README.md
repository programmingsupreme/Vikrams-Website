# Vikram Nadathur — Portfolio

My personal portfolio site, built with React and react-bootstrap, based on the
[soumyajit4419/Portfolio](https://github.com/soumyajit4419/Portfolio) template.

## Sections
- Home / intro
- About (education, honor societies, skills)
- Projects (Get Me Gas, AI Digital Twin, LSTM stock forecasting, CNN classifier)
- Resume (embedded PDF + download)

## Run locally
```
npm install --legacy-peer-deps
npm start
```

## Build for deployment
```
npm run build
```
